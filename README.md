# Village Background Studio

Node.js and Express application for generating 2D Indian village cartoon backgrounds with Google's Gemini image-generation API.

## Setup
- Node.js 18+
- Google Gemini API key with image generation access (billing may be required).

Set `GEMINI_API_KEY` in your hosting environment. Never expose it in browser code or commit it to GitHub. Set `GEMINI_IMAGE_MODEL` to a supported image generation model for your account.

Run with `npm install` then `npm start`.

Image generation API usage may incur charges. This app is not free or unlimited by default.
